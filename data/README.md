# Демонстрационные данные

`sample_calls.json` — 52 расшифровки звонков, полученные из API партнёра
(`GET https://utmn-api.uralmicro.ru/api/v1/calls`) во время работы над кейсом.

Что важно знать:

- все звонки **синтетические**, подготовлены организаторами кейса;
- телефоны замаскированы (`+7*******50`), чтобы в репозиторий не попали даже синтетические номера;
- один и тот же текст разговора встречается в API под разными `id` — в файле оставлена одна копия
  каждого уникального разговора, поэтому 52 записи соответствуют 50+ заготовленным сценариям;
- файл используется в тестах (`tests/test_corpus.py`) и в демо (`scripts/seed_demo.py`).

Структура одной записи:

```json
{
  "id": "PLKWT67VBE5KSTFEGEH27K5KK5",
  "operator_id": 3,
  "client_phone": "+7*******50",
  "started_at": "2026-10-29T10:35:51Z",
  "ended_at": "2026-10-29T10:40:07Z",
  "transcript": [
    { "speaker": "operator", "text": "Добрый день, служба поддержки «Сфера», меня зовут Сергей." },
    { "speaker": "client", "text": "Действует ли акция на ноутбуки?" }
  ]
}
```

`transcript` — размеченная расшифровка «оператор/клиент», ровно в том виде, в каком её присылает
программа-отправитель на вебхук.
