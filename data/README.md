# Демонстрационные данные

Два файла, оба получены из API партнёра `GET https://utmn-api.uralmicro.ru/api/v1/calls`.

| Файл | Звонков | Задач | Назначение |
|---|---|---|---|
| `sample_calls.json` | 52 | 189 | канонический набор: тесты, демо, цифры в README и презентации |
| `sample_calls_extra.json` | 48 | 170 | добор из API позже: проверка на комбинациях, которых не было при разработке |
| `sample_verification.json` | 4 | 2 пары | демонстрация проверки исполнения: подтверждение и опровержение |

Все звонки **синтетические**, подготовлены организаторами кейса. Телефоны заменены на
синтетические уникальные номера (`+7900…`): исходная маска `+7*******50` совпадала у разных
клиентов, и проверка исполнения принимала чужие реплики за подтверждение.

## Почему два файла

API не отдаёт фиксированный список: каждый запрос возвращает звонки с новыми `id`, а текст
собирается из блоков «вопрос клиента → ответ оператора» с рандомизацией компании и имени
оператора. При первом сборе (52 записи) часть комбинаций не встретилась. Позже мы добрали
ещё 48 уникальных расшифровок — и на них проверили, что детектор и парсер сроков не ломаются
на незнакомых комбинациях (`tests/test_extra_corpus.py`).

Канонический набор оставлен отдельно, чтобы цифры в документации и презентации оставались
воспроизводимыми: 52 звонка → 189 задач → 3,63 обещания на звонок.

## Как обновить данные

```powershell
# только посмотреть, что сейчас отдаёт API, и сравнить с репозиторием
python tools\refetch_calls.py

# добрать новые уникальные расшифровки в sample_calls_extra.json
python tools\collect_extra.py --target 55
```

Сервисный токен команды берётся из `.env` (`URALMICRO_SERVICE_TOKEN`), файл в `.gitignore`.

## Структура записи

```json
{
  "id": "PLKWT67VBE5KSTFEGEH27K5KK5",
  "operator_id": 3,
  "client_phone": "+7*******50",
  "started_at": "2026-10-29T10:35:51Z",
  "ended_at": "2026-10-29T10:40:07Z",
  "transcript": [
    { "speaker": "operator", "text": "Добрый день, служба поддержки «Сфера», меня зовут Сергей." },
    { "speaker": "client", "text": "Действует ли акция на ноутбуки?" }
  ]
}
```

`transcript` — размеченная расшифровка «оператор/клиент» ровно в том виде, в каком её присылает
программа-отправитель на вебхук.
