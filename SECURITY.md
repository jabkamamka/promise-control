# Безопасность

## Что важно знать про этот прототип

Сервис создан для хакатона и **не предназначен для эксплуатации с реальными
персональными данными**. По умолчанию:

- API и вебхук **не требуют авторизации** — любой, кто знает адрес, может отправить
  звонки или изменить статус задачи;
- CORS открыт (`allow_origins=["*"]`), чтобы демонстрационная панель работала с любого адреса;
- данные лежат в SQLite-файле рядом с приложением;
- телефоны в демонстрационных данных синтетические.

## Что включить перед реальным использованием

| Риск | Мера |
|---|---|
| Чужие звонки на вебхук | задать `WEBHOOK_TOKEN` и передавать заголовок `X-Webhook-Token` |
| Доступ к задачам и статусам | авторизация оператора: `Authorization: Bearer <access_token>` + проверка через `POST /auth/introspect` API УралМикро |
| Чтение персональных данных | роли (оператор видит свои задачи, руководитель — сводку), маскирование телефонов в выдаче |
| Открытый CORS | сузить `allow_origins` до адреса панели |
| Утечка базы | не публиковать `data/*.db`, `.env`; делать резервные копии |

Подробный план — в [docs/ROADMAP.md](docs/ROADMAP.md), раздел P1.

## Как сообщить о проблеме

Откройте issue в репозитории с пометкой `security`, не публикуя персональные данные,
токены и содержимое реальных звонков. Если проблема критическая — напишите владельцу
репозитория напрямую.
