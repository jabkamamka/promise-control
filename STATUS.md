# Статус работы

Обновляется агентами при завершении задачи. Общей памяти у агентов нет, поэтому
единственный достоверный источник — этот файл и коммиты.

## Сделано

- [x] API: `POST /webhook/calls`, `GET /calls`, `GET /tasks`, `PATCH /tasks/{id}/status`,
      `GET/POST /promise-types`, `GET /stats` — `app/main.py`.
- [x] Поиск обещаний: 3 встроенных типа, роли, отрицания, разбиение на смысловые куски — `app/detector.py`.
- [x] Сроки: относительные, «до конца дня/недели», дни недели, явные даты, дефолт +24 ч — `app/datetime_ru.py`.
- [x] Защита от дублей: `calls.id` + `UNIQUE(call_id, dedupe_key)` — `app/db.py`, `app/service.py`.
- [x] Автоматическая просрочка: фоновая задача + проверка при чтении — `app/main.py`, `app/service.py`.
- [x] Панель оператора и демо-сценарий — `static/dashboard.html`, `demo/run_demo.py`.
- [x] 34 теста, включая совместимость с настоящим `sender_windows_amd64.exe` — `tests/`.
- [x] Разбор записи организаторов — `docs/analiz_zapisi_8.md`.
- [x] Материалы защиты: план на 7 минут, чек-лист демо, 12 вопросов жюри — `docs/vystuplenie.md`.

## В работе

- Ничего: минимальный уровень кейса закрыт, идёт полировка перед защитой.

## Исправлено после независимого ревью

- Экранирование данных из звонка в панели (XSS через цитату).
- `?overdue=true` возвращал пусто: фильтр смотрел на старый статус после авто-проверки.
- Дата без часового пояса трактовалась как UTC, а не как время контакт-центра;
  добавлен `tzdata` — на Windows базы поясов нет из коробки.
- Просроченную задачу можно было «вернуть в работу» без нового срока, и она снова
  становилась просроченной: теперь нужен `due_at`.
- Новый тип без `keywords`/`patterns` угадывал слова из описания и дублировал
  встроенные типы: теперь 422 с объяснением.

## Известные ограничения

- Живой API УралМикро не отдаёт звонки команде без операторов: `POST /operators`
  отвечает 405, создать операторов публичным методом нельзя. Совместимость с
  отправщиком проверена через локальную заглушку `tools/mock_api.py`.
- Поиск обещаний — правила, а не LLM: сложные перефразирования могут не распознаться.
- Нет уведомлений и авторизации API (по кейсу не требуется на минимальном уровне).
